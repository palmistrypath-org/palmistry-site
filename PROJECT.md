# Palmistry Path — Compatibility Pointer

- `AGENTS.md` — shared operating policy and definition of done
- `CLAUDE.md` — Claude model routing/token rules
- `docs/WIKI.md` — documentation index and what to read when
- `docs/PRODUCT_VISION.md` — durable product/editorial/brand direction
- `docs/CURRENT_STATE.md` — current implementation/product state
- `docs/ARCHITECTURE.md` — technical structure
- `docs/ROADMAP.md` — approved/current planning state
- `docs/DECISIONS.md` — durable decisions
- `docs/AI_HANDOFF.md` — immediate continuation context
- `docs/ACTIVE_TASK.md` — disposable current-task memory

Read only what the current task requires. The existing specialized editorial, SEO, email, visual, launch, and worksheet documents in `docs/` remain valid domain references and should be opened only when relevant.
